New Windows updates replace expiring Secure Boot certificates

🗞️ BleepingComputer 🕒 2026-01-14T04:57:33+09:00 🔗 原文を開く
Impact: High Other
原文リンク 日次トップ

Impact判定理由

Secure Boot証明書の更新はシステム起動の信頼性に直結し、未更新環境ではブートキット攻撃や起動不能リスクが発生する可能性があるため。自動更新対象外の環境では特に注意が必要。

🧾 要約（ChatGPT）

概要

Microsoftは、Windows 11 24H2および25H2向けに新しいSecure Boot証明書を自動配信し、既存の期限切れ証明書を置き換える更新を開始した。Secure BootはUEFI（Unified Extensible Firmware Interface）環境での起動時に信頼できるコードのみを実行させる仕組みであり、この更新は署名チェーンの信頼性維持を目的としている。これにより、古い証明書を悪用したブートキット攻撃のリスクを低減し、将来的なセキュリティ維持を図るものとみられる。

現場の学び

  • Secure Boot証明書の有効期限管理は、OS更新サイクルと密接に関係しており、証明書失効による起動障害を防ぐための監視が重要である。
  • 証明書更新はセキュリティ強化だけでなく、古い署名を利用した攻撃経路の遮断にも寄与するため、資産管理と連動した更新確認が求められる。
  • 特にオフライン環境や長期運用システムでは、自動更新が適用されないケースを想定し、手動適用手順を整備しておく必要がある。

初動・継続対応の示唆

  • Windows Update経由での証明書更新適用状況を確認し、未適用端末を特定する。
  • Secure Boot設定の有効化状態と証明書チェーンの整合性を点検し、改ざんや不正署名の混入がないかを検証する。
  • 今後の証明書ローテーションに備え、UEFIレベルの更新手順や監査ログ取得を標準運用に組み込む。

📌 キーワード解説

Secure Boot / セキュアブート

UEFIの機能で、起動時に信頼された署名付きコードのみを実行する仕組み。マルウェアがブートプロセスに介入することを防ぐ。

UEFI (Unified Extensible Firmware Interface)

従来のBIOSに代わるファームウェアインターフェース。OS起動前のハードウェア初期化やセキュリティ機能を提供する。

Bootkit / ブートキット

OS起動前に感染し、システム制御を奪うマルウェア。Secure Bootが無効または脆弱な場合に侵入が可能となる。

Certificate Chain / 証明書チェーン

信頼の根（ルート証明書）から対象証明書までの署名関係を示す連鎖構造。これが破損または期限切れになると信頼性が失われる。
