CISA Warns of Active Exploitation of Gogs Vulnerability Enabling Code Execution

CVE-2025-8110（CVSS 8.7）は認証済みユーザによるパストラバーサルから任意コード実行に至る重大な欠陥であり、CISAが実際の悪用を確認している。即時対応が推奨されるが、影響範囲は限定的な構成条件に依存するためCriticalではなくHighと判断する。

概要

米国CISA（Cybersecurity and Infrastructure Security Agency）は、Gitリポジトリ管理ツール「Gogs」に存在する重大な脆弱性CVE-2025-8110（CVSS 8.7）が実際に悪用されているとして、既知の悪用脆弱性（KEV）カタログに追加した。この脆弱性はリポジトリのファイルエディタ機能におけるパストラバーサルに起因し、攻撃者が任意のコードを実行できる可能性がある。Gogsは軽量なGitサーバとして中小規模組織でも広く利用されており、影響範囲は広い。

現場の学び

  • パストラバーサルは単なる情報漏えいにとどまらず、コード実行に直結するケースがあるため、Webアプリのファイル操作機能には特に入力検証を徹底すべきである。
  • KEVカタログへの追加は「実際に攻撃が観測された」ことを意味し、PoC（概念実証）段階ではなく実運用環境での悪用が進行している可能性が高い。
  • Gogsのような自前ホスト型開発ツールは、外部公開設定や認証強度の見直しを怠ると、内部コード資産の侵害につながる。

初動・継続対応の示唆

  • 該当バージョンを使用している場合は、直ちに最新版へアップデートし、不要な外部公開を制限する。
  • Webサーバやアプリケーションログを確認し、異常なファイルアクセスパターン（../を含むリクエストなど）を検知する。
  • CSIRTはKEVカタログの更新を定期的に監視し、自組織の資産管理台帳と突合して迅速なパッチ適用判断を行う体制を整える。

📌 キーワード解説

Path Traversal / パストラバーサル

ファイルパスの検証不備を突き、意図しないディレクトリやファイルにアクセスする攻撃手法。Webアプリケーションでは '../' などを利用して上位ディレクトリに移動し、機密情報や実行ファイルを操作される危険がある。

Code Execution / コード実行

攻撃者が任意のコードをシステム上で実行できる状態を指す。Webアプリの脆弱性を通じてサーバ権限を奪取されると、完全な侵害につながる。

Known Exploited Vulnerabilities (KEV) Catalog / 既知の悪用脆弱性カタログ

CISAが管理する、実際に悪用が確認された脆弱性の一覧。米国政府機関に対しては、掲載脆弱性の修正を期限付きで義務化している。

Gogs

Go言語で実装された軽量なGitリポジトリ管理ツール。自社サーバ上でGitHub類似の機能を提供できるため、オンプレミス開発環境で広く利用されている。
