概要

米国CISA（Cybersecurity and Infrastructure Security Agency）は、Gitリポジトリ管理ソフトウェア「Gogs」に存在する高深刻度の脆弱性CVE-2025-8110（CVSS 8.7）が実際に悪用されているとして、Known Exploited Vulnerabilities（KEV）カタログに追加した。この脆弱性はリポジトリのファイルエディタ機能におけるパストラバーサル（Path Traversal）に起因し、攻撃者が任意のコードを実行できる可能性がある。Gogsは軽量なGitサーバとして多くの開発環境で利用されており、影響範囲は広い。

現場の学び

  • パストラバーサルは入力検証不備から生じる典型的な脆弱性であり、Webアプリケーションのファイル操作機能を持つシステムでは特に注意が必要。
  • KEVカタログへの登録は「実際の悪用が確認された」ことを意味し、PoC（概念実証）段階を超えて攻撃キャンペーンに組み込まれている可能性が高い。
  • Gogsのようなセルフホスト型開発ツールは社内ネットワーク内に設置されることが多く、内部侵入後の横展開（Lateral Movement）の起点となるリスクがある。

初動・継続対応の示唆

  • 該当バージョンを使用している場合は、ベンダー提供の修正版または緩和策を即時適用する。
  • WebサーバログやGogsのアクセスログを確認し、異常なファイルパス要求や不審なリポジトリ操作を検知する。
  • KEV登録脆弱性は攻撃者のスキャン対象になりやすいため、外部公開環境では特に監視を強化する。
  • 開発環境の権限分離とバックアップ体制を見直し、万一の侵害時にコード改ざんや情報漏えいを最小化する。

📌 キーワード解説

Path Traversal / パストラバーサル

ファイルパスの検証不備を突いて、意図しないディレクトリやファイルにアクセスする攻撃手法。Webアプリケーションでのファイル編集・ダウンロード機能が狙われやすい。

Remote Code Execution (RCE) / リモートコード実行

攻撃者が遠隔から任意のコードを実行できる脆弱性のこと。システム乗っ取りやデータ改ざんに直結するため、最も危険な脆弱性クラスの一つ。

Known Exploited Vulnerabilities (KEV) Catalog / 既知悪用脆弱性カタログ

CISAが管理する、実際に悪用が確認された脆弱性の一覧。登録対象は米国政府機関に対して修正義務が課され、民間組織にも優先対応の指標となる。

Lateral Movement / 横展開

攻撃者が侵入後に他のシステムやアカウントへ移動して権限を拡大する行為。開発環境やCI/CDサーバが踏み台にされるケースが多い。
