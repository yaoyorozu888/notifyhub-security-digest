概要

Anthropicが提供するAI開発支援ツール「Claude Code」に、新機能Claude Code Securityが追加された。これはコードベースを自動スキャンし、脆弱性の検出と修正案の提示を行う機能で、現在はEnterpriseおよびTeam向けの研究プレビュー段階にある。AIによるコード解析を通じて、開発段階でのセキュリティ欠陥の早期発見を支援する狙いがある。一方で、AIモデルによる解析結果の精度や誤検知、ソースコード送信時の情報管理など、CSIRTとして留意すべき新たなリスクも内包する。

現場の学び

  • AIによる脆弱性診断は、従来のSAST/DASTと異なり、自然言語理解を活かした推論型検出が可能だが、誤検知率や再現性の評価が課題となる。
  • コードベースを外部AIに送信する場合、機密情報の取り扱いやデータ保持ポリシーを明確化しないと、情報漏えいリスクを招く。
  • AI支援による修正提案は有用だが、自動修正の適用判断は開発チームとセキュリティレビューの連携が前提となる。

初動・継続対応の示唆

  • 自組織でClaudeや類似AIツールを利用する場合、送信データの分類と匿名化方針を策定し、開発環境の分離を徹底する。
  • AI診断結果を既存の脆弱性管理プロセス（例：JIRA連携、脆弱性DB照合）に統合し、誤検知と再発防止のフィードバックループを構築する。
  • AIによるコード解析が増えることで、生成AIの安全利用ガイドライン（社内・法的）を更新する必要がある。

📌 キーワード解説

SAST（Static Application Security Testing）

ソースコードを静的に解析して脆弱性を検出する手法。DASTのように実行時挙動を見る手法と対比される。

DAST（Dynamic Application Security Testing）

実行中のアプリを外部からテストして脆弱性を検出する。SASTと異なり、実行環境依存の欠陥を見つけやすい。

AI-assisted code analysis（AI支援コード解析）

生成AIがコード文脈を理解し脆弱性を推論する手法。従来のルールベース検出より柔軟だが誤検知リスクがある。

Research Preview（研究プレビュー）

正式版前の試験提供段階。精度・安全性が保証されず、商用利用時はリスク評価が必要。
