概要

Palo Alto Networksは、PAN-OSに存在する重大なバッファオーバーフロー脆弱性（CVE-2026-0300）が実際に悪用されていることを警告した。問題はUser-ID Authentication Portalがインターネットからアクセス可能な状態で構成されている場合に、認証なしでリモートコード実行を許す点にある。CVSSスコアは9.3で、攻撃者はこの経路を通じてファイアウォール上で任意コードを実行し、制御権の奪取やネットワーク横断的な侵入を行う可能性がある。影響範囲は外部公開された管理・認証ポータルを持つ環境に集中するが、クラウド管理やVPN連携を行う構成では被害が拡大しやすい。現時点で攻撃の詳細手法は未公開だが、限定的標的攻撃から広範囲スキャンへの移行が懸念される。CSIRTとしては、該当機能の無効化やアクセス制限を即時実施し、ログ監査で不審な認証試行・プロセス生成を確認することが重要である。

📌 キーワード解説

Buffer Overflow（バッファオーバーフロー）

メモリ領域を超えてデータを書き込むことで任意コード実行を引き起こす脆弱性。入力検証不備が主因で、RCEの典型経路となる。

User-ID Authentication Portal

PAN-OSのユーザ識別機能を提供するWebポータル。外部公開時は攻撃面が広がるため、アクセス制御が重要。

Remote Code Execution（RCE）

攻撃者が遠隔から任意コードを実行できる状態。認証前RCEは防御困難で、ネットワーク境界防御を突破する起点となる。

Exploit in the wild（実際の悪用）

脆弱性が実際に攻撃で利用されている状態。PoC公開よりも深刻で、即時の封じ込め判断が必要。

深掘り解説

PAN-OSにおける管理・認証ポータルの露出リスクを再評価する

PAN-OSでは、User-IDやGlobalProtectなどのWebポータルが便利な一方で、管理系機能と同一OS上で動作するため、脆弱性が出た際に防御層が薄くなる。特にUser-ID Authentication Portalは認証前に通信を受け付けるため、RCE脆弱性が存在するとインターネット経由で即座に侵入を許す。実運用では、(1) 管理ポータルを外部公開しない、(2) 必要な場合はVPN経由限定とする、(3) GeoIPやACLでアクセス元を制限する、(4) PAN-OSの自動アップデートを有効化する、などの対策が有効である。過去のCVE-2024-3400でも同様の構成が被害拡大要因となった。CSIRTは、設定監査でportal機能の露出状況を定期確認し、攻撃面の縮小を継続的に実施すべきである。
