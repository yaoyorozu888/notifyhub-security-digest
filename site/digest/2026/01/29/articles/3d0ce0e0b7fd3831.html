Fake Moltbot AI Coding Assistant on VS Code Marketplace Drops Malware

Impact判定理由

公式Marketplace経由で配布されたマルウェアであり、開発環境への侵入経路として実被害リスクが高い。公的機関発表ではないが、一次調査報告に基づく具体的挙動が確認されており、実運用上は高優先度で対応が必要。

🧾 要約（ChatGPT）

概要

Microsoft Visual Studio Code Marketplace上で公開されていた拡張機能「ClawdBot Agent - AI Coding Assistant」が、実際にはマルウェアをドロップする偽AIコーディング支援ツールであることが報告された。開発者名義は「Moltbot（旧Clawdbot）」を装っており、正規のAI支援ツールを模倣して信頼を得る手口である。感染後は外部C2サーバと通信し、追加のペイロードを取得・実行する挙動が確認されている。VS Code Marketplaceは公式チャネルであるため、利用者は署名やレビューを過信しやすく、サプライチェーン型の侵入経路として特に注意が必要である。

現場の学び

  • 公式マーケットプレイスであっても拡張機能の信頼性検証は必須であり、開発者名や公開履歴の確認を怠るとリスクが高い。
  • AI支援ツールなど新興カテゴリは、開発者が頻繁に更新・再ブランド化を行うため、名称類似によるなりすましを見抜く観点が重要。
  • 開発環境へのマルウェア混入は、ソースコード汚染や資格情報窃取を通じて組織全体への横展開につながる。

初動・継続対応の示唆

  • VS Code拡張のインベントリを取得し、「clawdbot.clawdbot-agent」など不審な識別子を含むものを即時隔離・削除する。
  • 開発端末の通信ログを確認し、未知のC2通信や外部スクリプト取得の痕跡を検知指標として活用する。
  • 開発環境の拡張導入ポリシーを見直し、署名検証・集中配布などの統制を導入して再発防止を図る。

Supply Chain Attack（サプライチェーン攻撃）

C2（Command and Control）通信

AI Coding Assistant（AIコーディング支援ツール）

開発支援を目的とした生成AIツール。利便性が高い一方で、偽装やデータ流出リスクが混在する。
