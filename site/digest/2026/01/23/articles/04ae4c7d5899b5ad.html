CVE-2025-68645 Synacor Zimbra Collaboration Suite (ZCS) PHP Remote File Inclusion Vulnerability

概要

CISAのKnown Exploited Vulnerabilities（KEV）カタログに、CVE-2025-68645としてSynacor Zimbra Collaboration Suite (ZCS)のPHPリモートファイルインクルード（RFI）脆弱性が追加された。攻撃者は認証を経ずに外部から任意ファイルを読み込み・実行できる可能性があり、リモートコード実行（RCE）やサーバ乗っ取りに直結する。ZCSは多くの自治体・教育機関・中堅企業でオンプレミス運用されており、メール・カレンダー基盤として業務中枢に位置するため、侵害時の影響は横展開・情報漏えい・メール転送ルール改ざんなど多岐に及ぶ。既に悪用が確認されている点が最大の懸念である。

現場の学び

  • 認証前RFIはWeb層のWAFやリバースプロキシでは完全に防げず、アプリ層のパッチ適用が唯一の確実策。
  • メール基盤は「通信経路が限定的」と誤認されやすいが、ZCSは外部公開APIや管理ポートが多く、露出面が広い。
  • 侵害後はWebシェル設置やcron登録などで持続化される傾向があり、単純な再起動では復旧しない。

初動・継続対応の示唆

  • 対象バージョンを即確認し、ベンダー提供の修正版または緩和策を適用。パッチ未提供の場合は外部公開を一時遮断も検討。
  • Webログでincludeやrequireを伴う外部URL呼び出し、/public/配下の異常アクセスを確認。
  • 侵害確認時はメール転送設定・管理者アカウント・cronジョブを重点的に調査し、横展開防止の封じ込めを優先。

Remote File Inclusion（RFI）

外部のファイルをサーバ側で読み込む脆弱性。LFI（ローカルファイルインクルード）と異なり、攻撃者が任意コードを実行可能。

CISA KEV

CISAが公表する既に悪用が確認された脆弱性リスト。掲載は実際の攻撃利用を意味し、即時対処が推奨される。

Zimbra Collaboration Suite（ZCS）

メール・カレンダー統合基盤。オンプレ運用が多く、外部公開APIが多いため攻撃面が広い。

Webシェル

攻撃者が設置する遠隔操作用スクリプト。削除しても再生成されることがあり、持続化の指標となる。
