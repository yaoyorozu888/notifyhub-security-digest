概要

Next.jsが10月14日、キャッシュ処理とSVG画像処理に関係する重大な脆弱性2件と、サービス拒否につながる高深刻度の脆弱性1件を修正する、通常の更新時期外のセキュリティ更新を公開したと報じられた。報道によれば、コード実行の脆弱性の一方はReact Server Componentsに、もう一方はsharpパッケージ経由で利用するSVG処理ライブラリlibrsvgに存在し、認証なしでの遠隔コード実行が可能とされる。影響を受ける版を使い、攻撃者から該当する処理経路へ到達できる環境では、アプリケーションの実行権限で処理を実行され、設定情報や秘密情報の窃取、同一環境内への侵入拡大につながるおそれがあるが、記事から具体的な成立条件や権限範囲は確認できない。サービス拒否の脆弱性は可用性に影響しうるものの、負荷の規模やキャッシュへの影響は示されていない。影響を受けるバージョン、CVE番号、悪用の確認状況は未確認であり、まず稼働中のNext.jsとsharpの利用状況を洗い出し、一次情報で対象版と修正版を照合したうえで、外部公開システムから更新を優先する必要がある。

📌 キーワード解説

React Server Components（サーバーコンポーネント）

サーバー側で画面用の処理を実行する仕組み。ブラウザー内で完結する処理と異なり、脆弱性が実行に結び付けばサーバー権限への影響が生じうる。

librsvg（SVG処理ライブラリ）

SVG画像を解析・変換するライブラリ。単なる画像表示と異なり、サーバーが攻撃者提供の画像を処理する構成では、入力処理が攻撃面となる。

Out-of-band update（通常時期外の更新）

定例の更新周期を待たずに提供される修正。定例更新とは異なり緊急性を示唆するが、対象版や悪用状況の確認は別途必要となる。

深掘り解説

画像処理をサーバーの攻撃面として評価する

画像処理は表示機能の一部に見えやすいが、サーバーが受け取ったファイルを解析・変換するなら、実際には外部入力を扱う処理系となる。SVGのように構造を持つ形式では、拡張子や申告された形式だけで安全性を判断できない。例えば、利用者が画像を投稿し、サーバーがsharpでSVGを変換するサービスでは、アップロード機能の有無だけでなく、変換処理の実行場所、実行ユーザーの権限、外向き通信やファイル参照の制限を確認する。更新までの暫定措置として処理経路を止める場合、画像投稿やサムネイル生成が業務に与える影響も合わせて判断する。
