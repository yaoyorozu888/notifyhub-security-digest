China-Aligned Hackers Hijack Sogou Input Method DNS Requests to Deploy DarkVigil Backdoor

該当ソフトウェアを利用する端末で通信への介入が成立すれば、バックドアによる監視や追加侵害につながる可能性がある一方、標的範囲や侵入後の影響は未確認。 ニュース媒体の記事であり、提示情報も要約途中のため、媒体補正による引き上げは行わず、実組織への適用条件が限定される点を踏まえてMediumと評価。

概要

中国と連携する攻撃者と評価されるSlippyNunchucksによる、Windows版Sogou Input Methodを足掛かりとした監視目的の侵入活動が報告された。攻撃者は同ソフトウェアの安全でないHTTP通信を悪用し、DNS要求に介入してDarkVigil（FDMTPとも呼ばれる）バックドアを展開したとされる。成立には、対象端末で該当ソフトウェアが使われ、攻撃者が通信へ介入できる条件が関係するとみられるが、具体的な介入位置や必要な設定は提示情報から確認できない。バックドアが端末上で実行されれば監視活動の足場になり得る一方、他端末への横展開や認証情報窃取まで実施されたかは未確認となる。活動は2026年7月1日から観測されたとされ、組織や個人を対象にしたと記されているものの、提示された記事要約は途中で切れており、標的の範囲、被害件数、侵入後の具体的な操作、侵害指標は確認できない。まずは利用端末の有無と通信経路を照合し、同ソフトウェアの通信に異常な応答や不審な実行ファイルの生成がないかを確認する必要がある。

📌 キーワード解説

DNS hijacking（DNS乗っ取り）

名前解決の結果を攻撃者側へ誘導し、通信先を変える手口。正規通信の改ざんとは異なり、名前解決経路への介入が焦点となる。

HTTP（暗号化されないウェブ通信）

通信内容の暗号化や相手先の真正性確認がHTTPSより弱い。通信経路を守るだけでは防げない端末側の侵害と区別して調べる必要がある。

Backdoor（バックドア）

侵入後に外部から操作を続けるための仕組み。初期侵入手段とは異なり、端末上での継続的な制御や情報収集に関わる。

深掘り解説

正規ソフトウェアの通信を信頼しすぎない

端末に導入済みのソフトウェアであっても、その通信が常に安全とは限らない。暗号化されないHTTP通信では、経路上で応答が差し替えられた場合、利用者や運用担当者が正規の処理と攻撃者の介入を見分けにくくなる。対策を通信の遮断だけに寄せると、業務機能を止める一方で、端末上に残った不審な実行ファイルや実行後の通信を見逃すおそれがある。例えば、Sogou Input Methodの利用端末を特定したうえで、通信先・応答の変化、プロセスの起動元、未知のファイル生成を時系列で突き合わせる。異常端末はネットワークから隔離し、業務上必要な入力機能への影響を確認してから、更新・削除や再イメージ化を判断する。通信の異常だけで侵害を断定せず、端末上の実行痕跡と合わせて評価することが重要となる。
