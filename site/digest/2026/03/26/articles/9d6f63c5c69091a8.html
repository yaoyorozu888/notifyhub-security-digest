概要

Huntressの報告によると、Microsoft 365 の認証基盤を狙うDevice Code Phishing攻撃が、米国・カナダ・豪州・ニュージーランド・ドイツの340以上の組織で観測された。攻撃は2026年2月19日に初確認され、以降急速に拡大している。この手法はOAuthのデバイスコード認証フローを悪用し、ユーザーが正規のMicrosoftログインページでコードを入力するよう誘導する点が特徴である。攻撃者は被害者の承認を経てアクセストークンを取得し、多要素認証を迂回してメールボックスやクラウド資産にアクセス可能となる。現時点で特定のマルウェア配布や横展開の証拠は限定的だが、持続的な認証トークン悪用による長期侵害の懸念がある。

判断ポイント

  • 本件はOAuthトークンの信頼境界を突く社会工学的攻撃であり、従来のフィッシング検知では捕捉困難。
  • 攻撃成立にはユーザー操作が必要だが、Microsoft公式ドメインを利用するため教育・警告の効果が限定的。
  • 影響範囲はID基盤全体に及ぶ可能性があり、トークン失効・アプリ承認監査が封じ込めの鍵となる。

対応アクション（今すぐ・継続）

  • [今すぐ] Microsoft Entra/Azure ADのサインインログでdevice code flow利用イベントを確認し、異常なクライアントIDを特定。
  • [今すぐ] 不審なOAuthアプリの承認取り消しと、影響ユーザーのトークン再発行を実施。
  • [継続] ユーザー教育を更新し、デバイスコード入力要求を伴う認証誘導を報告対象として明示する。

📌 キーワード解説

Device Code Flow（デバイスコード認証フロー）

ブラウザを持たない端末でOAuth認証を行う仕組み。正規のMicrosoftドメインを使うため、通常のフィッシング検知を回避しやすい。

OAuthトークン

外部アプリが認可を得てアクセスするための資格情報。パスワードとは異なり長期有効な場合があり、漏洩すると恒常的アクセスを許す。

多要素認証（MFA）迂回

認証プロセスの一部を正規経路で通過させることでMFAを無効化する手法。完全な突破ではなく、設計の盲点を突く。

トークン失効（Revoke Token）

既存のOAuthトークンを無効化する操作。パスワード変更だけでは無効化されない点が混同されやすい。
