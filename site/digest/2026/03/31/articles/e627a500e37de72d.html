概要

CERT/CCは、CrewAIにおいて複数の深刻な脆弱性（RCE、SSRF、任意ファイル読み取り）が確認されたと公表した。特にCVE-2026-2275はCode Interpreter Toolのフォールバック処理に起因し、Dockerが利用不可となった際に安全でないSandboxPythonへ切り替わることで任意コード実行が可能となる。他の3件（CVE-2026-2285, -2286, -2287）は不適切なデフォルト設定やランタイム検証不足により発生し、プロンプトインジェクションを通じて連鎖的に悪用される可能性がある。現時点で完全な修正版はなく、ベンダーは一部の対処方針を提示しているが、全脆弱性を解消する更新は未提供である。攻撃者はこれらを組み合わせてDockerホスト上でのサンドボックス回避や認証情報窃取、さらには横展開を実現できるため、AIエージェントを公開運用している環境では特に注意が必要である。

判断ポイント

  • 攻撃成立にはCode Interpreter Toolの有効化またはallow_code_execution=True設定が前提であり、開発・PoC環境での露出が主なリスク源となる。
  • RCE・SSRF・ローカルファイル読み取りが連鎖可能であり、単一脆弱性よりも複合悪用を前提にリスク評価すべき。
  • ベンダー対応が未完了であるため、恒久対策が存在しない期間における運用制御（無効化・隔離）が重要。

対応アクション（今すぐ・継続）

  • [今すぐ] Code Interpreter Toolを無効化し、allow_code_execution=True設定を削除または制限する。
  • [今すぐ] Docker稼働状態の監視を強化し、フォールバックでSandboxPythonへ移行しないよう設定を確認する。
  • [継続] CrewAIエージェントの入力経路を棚卸しし、外部入力に対するサニタイズ・検証を定常的に実施する。

📌 キーワード解説

SSRF（Server-Side Request Forgery）

サーバ側が攻撃者指定のURLへリクエストを送る脆弱性。外部から内部ネットワークやクラウドメタデータへのアクセスを誘発する点が特徴。

RCE（Remote Code Execution）

リモートから任意コードを実行される脆弱性。権限昇格や持続化の起点となりやすく、封じ込めが遅れると横展開に発展する。

Prompt Injection（プロンプトインジェクション）

LLMやAIエージェントに対し、意図しない命令を入力文で注入する攻撃。入力検証や権限分離が不十分な場合に成立する。

Sandbox（サンドボックス）

安全な実行隔離環境。CrewAIではDockerが本来のサンドボックスだが、フォールバック先のSandboxPythonは制約が弱く、RCEに悪用される。
