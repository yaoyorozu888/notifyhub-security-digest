CVE-2025-32432 Craft CMS Code Injection Vulnerability

Impact: Critical Vulnerability

Impact判定理由

Craft CMSのコードインジェクションにより任意コード実行が可能で、CISA KEV掲載により実際の悪用が確認済み。公開Web資産への直接影響が大きく、攻撃経路の初動点となるためCritical評価。

概要

CISAのKnown Exploited Vulnerabilities（KEV）カタログに、CVE-2025-32432としてCraft CMSにおけるコードインジェクション脆弱性が追加された。Craft CMSはPHP製のコンテンツ管理システムで、企業サイトや官公庁サイトなどでも利用例がある。CISAの掲載は、すでに実際の悪用が確認されたことを意味し、公開環境にあるCraft CMSインスタンスが攻撃対象となる可能性が高い。攻撃者はこの脆弱性を利用して任意コード実行やシステム乗っ取りを行うことができ、Webサーバ経由での横展開や持続化にもつながりうる。

現場の学び

  • KEV掲載は「理論上の脆弱性」ではなく現実に攻撃が観測された段階であるため、PoCの有無に関わらず緊急対応が必要。
  • Craft CMSはプラグイン経由で構成が複雑化しやすく、バージョン混在やカスタムコードが修正適用を難しくする。影響範囲の棚卸しを優先。
  • Web CMS経由の侵入は、Webサーバ権限の奪取→内部ネットワークへの足掛かりという定型パターンを取るため、単点防御では不十分。

初動・継続対応の示唆

  • Craft CMSのバージョン確認と、ベンダー提供の修正版または緩和策の即時適用を実施。修正が未提供の場合は公開停止やWAFルール強化を検討。
  • Webアクセスログにおける異常なPOSTリクエストやテンプレート操作リクエストを確認し、不審なコード挿入痕跡を早期検知。
  • CMS管理者アカウントの認証情報再発行と、外部公開サーバの横展開防止（SSH鍵・APIトークンの棚卸し）を並行して実施。

📌 キーワード解説

Code Injection（コードインジェクション）

入力値を介して任意コードを実行させる攻撃。SQLインジェクションなどと異なり、直接アプリケーションロジックを乗っ取る点が特徴。

Craft CMS

PHP製のCMSで、テンプレートやプラグインの柔軟性が高い。構成の自由度が高い反面、権限設定や更新管理の不備が攻撃面を広げやすい。

CISA KEV

米CISAが公表する既に悪用された脆弱性リスト。PoCや攻撃観測が確認済みで、実際の被害防止に直結する優先修正指標。

WAF（Web Application Firewall）

Webアプリ層の攻撃を検知・遮断する仕組み。脆弱性修正が間に合わない場合の一時的防御策として有効。
