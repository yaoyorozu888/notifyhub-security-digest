概要

オープンソースの脆弱性スキャナ Trivy の GitHub Actions リポジトリが再び侵害され、75のタグが乗っ取られ、悪意あるコードが挿入された。改ざんされたアクション（aquasecurity/trivy-action および aquasecurity/setup-trivy）は、CI/CD 環境で利用される際に 認証情報やトークンを窃取 するマルウェアを配布していた。攻撃者は GitHub Actions の自動更新やバージョンピン留めの緩さを突き、開発パイプライン全体への侵入を狙ったとみられる。Aqua Security は既に修正済みだが、改ざん期間中にこれらのアクションを参照したワークフローは、シークレット漏えいのリスクがある。

現場の学び

  • CI/CD 用 GitHub Actions の バージョン固定（SHAピン留め） が不十分だと、依存元の改ざんを即座に取り込む危険がある。
  • OSS サプライチェーン攻撃は「信頼済みリポジトリ」経由で発生し得るため、自動更新やlatestタグ利用はリスク増大要因となる。
  • Secrets 窃取型マルウェアは、クラウド認証情報・署名鍵・APIトークンなど横展開の起点を奪うため、単一リポジトリ侵害でも被害範囲が広がる。

初動・継続対応の示唆

  • 該当アクションを利用していたリポジトリの 実行ログとSecrets履歴 を確認し、不審な外部通信やトークン再発行を即実施する。
  • CI/CD 環境の 依存アクションをSHAで固定 し、外部リポジトリ更新をレビュー経由に制限する。
  • OSS依存のセキュリティツール群（特にGitHub Actions連携）は、署名付きリリースと検証プロセスを導入して信頼性を担保する。

📌 キーワード解説

GitHub Actions

GitHub上でCI/CDを自動化する仕組み。外部リポジトリのアクションを取り込む点が特徴で、改ざん時は供給元から攻撃が波及する。

SHAピン留め

特定のコミットハッシュを指定してアクションを固定する手法。latestタグ利用と対比し、改ざんリスクを抑える。

Secrets

CI/CDで利用する認証情報やAPIキー。漏えい時はクラウド資産や署名鍵が奪取されるため、再発行と範囲特定が重要。

Supply Chain Attack（サプライチェーン攻撃）

信頼済みソフトウェアの更新経路を悪用する攻撃。直接侵入より検知が遅れやすく、CI/CD環境では特に深刻。
