Malicious npm Package Posing as OpenClaw Installer Deploys RAT, Steals macOS Credentials

Impact判定理由

macOS向けRATを配布する悪意あるnpmパッケージであり、開発端末やCI環境を侵害する恐れがある。npm上で公開中で拡散余地が残るが、現時点の感染規模は限定的。メディア由来情報のためCriticalには至らず。

概要

npmリポジトリ上で「@openclaw-ai/openclawai」という悪意あるパッケージが発見された。正規のOpenClawインストーラを装い、実際にはRAT(Remote Access Trojan)を展開し、macOS環境の認証情報を窃取する。公開日は2026年3月3日で、既に約178回ダウンロードされている。npm上で依然として入手可能である点が懸念される。攻撃者は開発者の信頼を悪用し、依存関係経由で開発環境やCI/CDパイプラインへの侵入を狙う可能性がある。

現場の学び

  • npmなどのパッケージサプライチェーンは、署名や検証が不十分な場合に容易に悪用される。特に小規模ライブラリを導入する際は、リポジトリ・作者の正当性確認が必須。
  • macOS環境を狙うRATは、開発端末やビルドサーバを踏み台にする意図が強い。開発者権限の高さが攻撃ROIを押し上げる。
  • npm install時の自動スクリプト実行(postinstall等)を悪用する手口は過去事例と共通しており、CI環境の無防備な実行が感染経路となり得る。

初動・継続対応の示唆

  • 自組織内で「@openclaw-ai/openclawai」パッケージの導入履歴を即時確認し、存在すればネットワーク隔離と認証情報変更を実施。
  • npm install時の外部通信ログや、未知ドメインへの接続をSIEMで検索し、RAT通信の有無を確認。
  • 今後の再発防止として、内部npmミラーの利用や、署名検証・依存関係固定(lockfile)の徹底を検討。

📌 キーワード解説

RAT (Remote Access Trojan)／リモートアクセス型トロイ

遠隔操作を目的とするマルウェア。通常のバックドアよりも機能が多く、継続的な制御や情報窃取を行う。

npm supply chain attack／npmサプライチェーン攻撃

npm等のパッケージ管理を悪用し、依存関係経由でマルウェアを拡散する手法。リポジトリ信頼性が鍵となる。

postinstall script／ポストインストールスクリプト

npm install時に自動実行されるスクリプト。便利だが悪用されると任意コード実行につながる。

CI/CD pipeline／継続的インテグレーション・デリバリ

自動ビルド・デプロイ環境。開発者権限を持つため、感染時の影響が大きい。
