概要

Microsoft Windows OS の WindowsAI 機能が作成するスケジュールタスクにおいて、任意のディレクトリを削除できる脆弱性が報告された。攻撃者がローカル権限を持つ環境で悪用した場合、システムフォルダや他ユーザ領域を削除し、サービス停止や永続化妨害を引き起こす可能性がある。現時点で Microsoft からの公式修正情報は確認されていないが、PoC や悪用事例は未確認。ScanNetSecurity による報道ベースであり、一次情報は未公開である。

現場の学び

  • 本件は権限昇格ではなく破壊型挙動に分類される。攻撃者視点では持続化妨害や痕跡隠蔽に利用される可能性があり、単純な DoS として軽視すべきでない。
  • WindowsAI 機能は近年の Windows 11 以降で自動有効化される傾向があり、管理者が意図せずスケジュールタスクを保持しているケースがある。
  • スクリプト実行や自動化処理の中でタスクスケジューラを利用している場合、同様の削除ロジックを含むか確認が必要。

初動・継続対応の示唆

  • WindowsAI 関連タスクの存在と権限設定を確認し、不明なタスクや不要な削除処理を停止する。
  • システムディレクトリや共有フォルダの削除イベント（Event ID 4660/4663 など）を監視し、異常な削除操作を早期検知する。
  • Microsoft 公式情報（MSRC、Windows Release Health）を継続監視し、修正パッチや設定回避策が公開された際に迅速に適用する。

📌 キーワード解説

WindowsAI

Windows 11以降で導入されたAI支援機能群。OS内部の自動化処理や推論モデルを利用するが、従来のCortanaやCopilotとは異なる実装。

スケジュールタスク (Scheduled Task)

Windowsの自動実行機構。権限設定や実行アカウントにより、誤設定時は権限昇格や破壊行為の踏み台となる。

任意ディレクトリ削除

攻撃者が指定したフォルダを削除できる欠陥。任意コード実行に比べ軽度だが、永続化妨害や証拠隠滅に悪用される。

DoS (Denial of Service)

サービス妨害攻撃。外部からのトラフィック型と異なり、内部操作によるファイル削除型DoSは検知が難しい。
