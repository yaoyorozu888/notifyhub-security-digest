Hackers Exploit Metro4Shell RCE Flaw in React Native CLI npm Package

Impact判定理由

CVE-2025-11953は認証不要RCE（CVSS 9.8）で実際の悪用が確認済み。開発環境経由での侵入リスクが高いが、一般公開サーバではないため影響範囲は限定的。情報源はメディア由来のためCriticalには補正せずHighとした。

🧾 要約（ChatGPT）

概要

人気のReact Native開発環境で利用されるnpmパッケージ「@react-native-community/cli」に含まれるMetro Development Serverにおいて、CVE-2025-11953（通称Metro4Shell）と呼ばれる重大なRCE脆弱性が悪用されていることが報告された。VulnCheckによると、2025年12月21日以降に実際の攻撃観測があり、CVSSスコアは9.8。認証不要で任意コード実行が可能であり、開発・CI環境や社内ネットワーク内で稼働するMetroサーバが踏み台となるリスクがある。React Native開発環境はしばしば内部ポートを露出したまま利用されるため、外部からの到達性がなくてもVPN経由や開発者端末経由で侵入される可能性がある。

現場の学び

  • 開発支援ツールでも常駐型サーバプロセスが存在する場合、攻撃面として無視できない。特にnpmパッケージ経由の依存関係は更新遅延が発生しやすい。
  • Metroサーバはデフォルトでポート8081を使用し、社内開発ネットワークで広く露出している傾向がある。CI/CD環境やテスト端末も含めたスキャンが必要。
  • 攻撃者は開発環境を初期侵入点として利用し、ソースコード窃取や署名鍵奪取などサプライチェーン攻撃に発展させる可能性がある。

初動・継続対応の示唆

  • 該当パッケージ利用プロジェクトを特定し、Metroサーバの稼働有無と露出範囲を即時確認。不要なポート公開を遮断。
  • npm依存関係を最新に更新し、修正版適用後にCI/CD環境のキャッシュを再構築。古いビルド環境の残存を防ぐ。
  • 過去ログからポート8081への外部アクセスやNodeプロセス起動履歴を調査し、不審なスクリプト実行を検知指標として活用。

📌 キーワード解説

RCE（Remote Code Execution）／リモートコード実行

攻撃者が遠隔から任意のコードを実行できる脆弱性。DoSや情報漏洩よりも制御奪取リスクが高い。

Metro Development Server

React Nativeのビルド・ホットリロードを提供する開発用サーバ。通常は内部利用だが、露出すると攻撃対象となる。

npmパッケージ

Node.js用の依存モジュール。更新遅延や依存関係の複雑化により脆弱性が残存しやすい。

サプライチェーン攻撃

開発・ビルド工程を狙う攻撃。運用環境への直接攻撃と異なり、信頼経路を悪用して侵入する点が特徴。
