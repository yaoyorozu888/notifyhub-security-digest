概要

米CISAのKnown Exploited Vulnerabilities（KEV）カタログに、CVE-2024-43468（Microsoft Configuration ManagerのSQLインジェクション脆弱性）が追加された。Configuration Manager（旧SCCM）は多くの企業で資産管理・パッチ配布に利用され、管理サーバがドメイン全体に高権限で接続しているケースが多い。攻撃者はこの脆弱性を悪用し、認証済みまたは特定のアクセス権を持つ状態からSQL経由で任意コード実行や構成情報の窃取を行う可能性がある。既に悪用が確認されており、CISAは連邦機関に対し速やかなパッチ適用を義務付けている。

現場の学び

  • Configuration Managerは管理基盤としての横展開リスクが高く、単一サーバ侵害が全社規模の被害に直結しうる。
  • SQLインジェクションはWebアプリ脆弱性の印象が強いが、管理コンソールやAPI層でも発生し得る点を再確認する。
  • KEV掲載＝実際の攻撃利用が観測済みであり、「パッチ未適用＝侵害リスク顕在化」と捉えるべき段階にある。

初動・継続対応の示唆

  • 該当バージョンの有無を即時確認し、MSRC提供の修正プログラムを適用する。テスト環境での適用検証を省略しない。
  • Configuration ManagerサーバのSQLログ・IISログを確認し、異常なクエリや不審な認証試行を調査する。
  • 管理サーバのネットワーク分離・権限最小化を再点検し、侵害時の横展開抑止を強化する。

📌 キーワード解説

SQL Injection（SQLインジェクション）

アプリケーションの入力値を通じてSQL文を改変し、データベース操作を不正に行う攻撃。入力検証不備が主因で、XSSとは異なりDB制御権を奪う。

Configuration Manager（SCCM）

Microsoftのシステム管理製品。資産管理・パッチ配布を集中管理する。侵害時はドメイン全体への横展開が容易になる。

CISA KEV

CISAが公開する既知悪用脆弱性カタログ。掲載は実際の攻撃利用が確認された証左で、即時対処が推奨される。

Privilege Escalation（権限昇格）

限定的な権限から管理者権限を奪取する行為。初期侵入後の横展開に利用される。認証前RCEとは異なり内部侵害段階で発生。
