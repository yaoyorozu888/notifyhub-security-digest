VU#504749: PyMuPDF path traversal and arbitrary file write vulnerabilities

🗞️ CERT/CC 🕒 2026-02-13T03:05:13+09:00 🔗 原文を開く
Impact: High Vulnerability

Impact判定理由

任意ファイル書き込みによりローカル権限下での改ざん・持続化が可能。管理者権限で実行されるとシステム破壊・昇格リスクがある。CERT/CC公表により悪用実現性が高いと判断し、ベースHighを維持。

🧾 要約（ChatGPT）

概要

CERT/CCは、PyMuPDF 1.26.5に存在するパストラバーサルおよび任意ファイル書き込み脆弱性（VU#504749）を公表した。embedded_get関数がPDF内の埋め込みファイルのメタデータを信頼して出力先パスとして使用するため、攻撃者が細工したPDFを処理させることで任意の場所にファイルを書き込むことが可能となる。ユーザ権限で実行される場合でも任意ファイル作成が可能であり、管理者権限で実行されるとシステムファイルの上書きや権限昇格につながる恐れがある。修正版は1.26.7で提供済み。

現場の学び

  • この脆弱性はユーザが信頼しないPDFを処理する運用で特に危険。自動処理ジョブやサーバサイドのPDF解析機能では、入力ファイルの検証不足が即リスク化する。
  • 「任意ファイル書き込み」は単なるファイル破壊にとどまらず、cronやサービス設定の改変などを通じて持続化に利用され得る。
  • Pythonライブラリを経由した脆弱性は、アプリケーションコード側でのパス検証やsandbox実装の有無で影響が大きく変わる。依存関係の更新だけでなく、安全なファイル出力設計の再確認が必要。

初動・継続対応の示唆

  • PyMuPDFを利用するシステムは1.26.7以降へ更新し、旧バージョンを含む仮想環境やDockerイメージも再ビルドする。
  • PDF処理機能を提供するWeb/APIサーバでは、アップロードPDFの検証と出力ディレクトリの固定化を確認。ファイルパスを外部入力から生成しない。
  • 既存の監査では、アプリケーションログやファイルシステムの異常（意図しない場所への書き込み）を検知指標として運用監視に組み込む。

📌 キーワード解説

Path Traversal（パストラバーサル）

ファイルパスに../などを挿入し、意図しないディレクトリへアクセスする攻撃。ディレクトリトラバーサルと混同されやすいが、目的は任意ファイル操作にある。

Arbitrary File Write（任意ファイル書き込み）

攻撃者が指定した場所に任意内容のファイルを書き込む脆弱性。任意コード実行の前段階として利用されることが多い。

Privilege Escalation（権限昇格）

低権限ユーザがシステムや管理者権限を奪取する行為。任意ファイル書き込みと組み合わせると実現しやすい。

Sandbox（サンドボックス）

アプリを隔離実行する仕組み。ファイルアクセス範囲を制限でき、パストラバーサル対策として有効。
