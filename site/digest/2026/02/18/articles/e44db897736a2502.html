SmartLoader Attack Uses Trojanized Oura MCP Server to Deploy StealC Infostealer

Impact: High Malware

Impact判定理由

正規ツールを装ったトロイ化配布により開発・AI連携環境が侵害されるリスクが高い。情報窃取型マルウェアStealCの実害性も大きい。一次情報はメディア由来だが技術詳細が具体的で、実運用上の警戒度は高い。

🧾 要約（ChatGPT）

概要

研究者は、新たなSmartLoaderキャンペーンを報告した。攻撃者は、Oura社のModel Context Protocol (MCP) Serverを模倣したトロイ化版を配布し、情報窃取型マルウェアStealCを展開している。MCP ServerはAIアシスタントとOura Ringの健康データを連携させる正規ツールであり、信頼性を悪用したサプライチェーン型の偽装攻撃が行われている。配布経路は不明だが、開発者やAI連携環境を狙った感染拡大が想定される。感染後は、ブラウザやクレデンシャル、暗号資産ウォレット情報などを窃取する。

現場の学び

  • 攻撃者は正規開発者向けツールのクローンを利用し、信頼の連鎖を逆手に取る。署名や配布元確認の自動化が不十分な環境では、容易に混入する。
  • StealCは既知の情報窃取系マルウェアで、SmartLoaderが中継役となる多段構成を取る。初期感染点の特定が困難で、EDR単体では検知が遅れやすい。
  • AI連携やIoTヘルスデータなど、非従来IT領域のAPI接続が新たな侵入面となりつつある。CSIRTはこれらの接続経路のリスク評価を更新すべき。

初動・継続対応の示唆

  • Oura関連やMCP Serverを名乗る実行ファイル・プロセスを監査し、署名・ハッシュ検証を徹底する。未知バイナリの通信先にSmartLoader関連C2が含まれる場合は即遮断。
  • StealCの通信パターン（HTTP POST先ドメイン、暗号化形式）をIOCとしてSIEMに登録し、情報窃取後の外向き通信を監視する。
  • AI連携や健康データAPIを扱う開発環境を分離し、開発者端末の供給元信頼性を再確認する。特にGitHub等からのバイナリ直接取得を制限する。

📌 キーワード解説

SmartLoader

多段感染を行うローダ型マルウェア。単体では無害に見えるが、後段で本命のマルウェアを取得する点でDropperと異なる。

Model Context Protocol (MCP)

AIアシスタントが外部データにアクセスするための通信プロトコル。APIキー管理が甘いと、偽装サーバ経由で情報漏洩しやすい。

StealC

情報窃取型マルウェアの一種。ブラウザやウォレット情報を収集しC2へ送信する。近年はSmartLoader経由で配布される傾向がある。

Trojanized Software

正規ソフトを装い悪意あるコードを含む改変版。Supply Chain攻撃と異なり公式配布経路外で拡散されることが多い。
