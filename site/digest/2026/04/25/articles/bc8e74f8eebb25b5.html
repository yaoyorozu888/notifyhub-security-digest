概要

中国語話者を標的とする攻撃キャンペーンが確認され、Tropic Trooper（別名Earth Centaur）がトロイ化されたSumatraPDFを用いてマルウェアを配布している。感染後はAdaptixC2 Beaconが展開され、攻撃者はこれを通じて被害端末を遠隔操作し、最終的にVisual Studio Code Tunnels機能を悪用して持続的なリモートアクセスを確立する。この手法は、正規の開発ツールやGitHubリポジトリを悪用する点で検知を困難にしており、ソフトウェア配布経路の信頼性を揺るがす。現時点で被害範囲は限定的とみられるが、同様の手法が他地域や他言語圏に転用される可能性がある。攻撃の初期侵入経路やGitHub上の配布範囲については未確認事項が残る。

📌 キーワード解説

トロイ化（Trojanized）

正規ソフトに悪意あるコードを埋め込み配布する手法。偽装配布（Fake Installer）と異なり、実際に正規機能も動作するため検知が難しい。

AdaptixC2

攻撃者が遠隔操作に用いるC2（Command and Control）フレームワーク。通信の難読化や多段構成により防御回避を狙う。

VS Code Tunnels

Visual Studio Codeのリモート開発機能。SSH不要で外部から接続できるため、悪用されると社内ネットワークへの裏口となる。

Tropic Trooper

東南アジアを中心に活動するAPTグループ。政府・軍・医療・製造などを標的とし、正規ツール悪用を得意とする。

深掘り解説

開発ツール悪用型攻撃への備え方

開発環境は一般的に高権限ユーザが多く、セキュリティ監視の盲点になりやすい。今回のようにVS Code TunnelsやGitHub経由での侵入が成立すると、EDRやプロキシでの検知が困難になる。実務上は、(1)開発端末のインターネットアクセス制御、(2)VS Code Tunnels等の外部接続機能を組織ポリシーで明示的に許可制にする、(3)GitHubリポジトリの署名付きリリースのみを許可する、などの対策が有効である。特にCI/CD環境では、開発者が「便利だから」と外部トンネルを開ける行為が横展開の起点になりやすい。開発部門とCSIRTの連携を強化し、ツール利用実態の可視化を進めることが防御の第一歩となる。
