概要

VulnCheckの報告によると、Flowise AI Agent Builderに存在するCVE-2025-59528（CVSS 10.0）のコードインジェクション脆弱性が、すでに実際に悪用されている。FlowiseはオープンソースのAIエージェント構築プラットフォームであり、攻撃者はCustomMCPノードの設定入力を悪用して任意コードを実行できる。この脆弱性は認証不要で利用可能な構成も多く、12,000件以上のインスタンスがインターネット上に露出しているとされる。悪用によりホストサーバ上での完全なリモートコード実行が可能で、AIワークフローに埋め込まれた資格情報やAPIキーの窃取、他システムへの横展開が懸念される。現時点で修正版の有無は明確でなく、攻撃の規模や侵害範囲の詳細は未確認である。

判断ポイント

  • 本脆弱性は認証前RCEであり、PoC不要で即時悪用可能な設計上の欠陥である。
  • AI開発環境やPoCサーバなど、通常監視が手薄な領域にFlowiseが導入されているケースが多く、検知遅延リスクが高い。
  • 攻撃者視点では、AI連携用のAPIキーやクラウド資格情報を奪取し、他環境への横展開やクラウドリソース悪用に繋げやすい。

  • [今すぐ] 公開インスタンスの有無を確認し、該当する場合は直ちに外部公開を停止またはアクセス制限を適用する。

  • [継続] Flowiseの更新情報・修正版リリースを監視し、再発防止のためにAI開発環境の構成管理・露出監査を定期化する。

📌 キーワード解説

RCE（Remote Code Execution）

攻撃者が遠隔から任意コードを実行できる脆弱性。情報漏えい型と異なり、完全なシステム支配に直結する。

コードインジェクション

入力値を通じて任意のコードを挿入・実行させる攻撃。コマンドインジェクションと異なり、アプリ内部ロジックを乗っ取る。

AI Agent Builder

AIモデルを組み合わせて自動処理を構築する開発基盤。通常は管理者権限で動作するため、侵害時の影響が大きい。

横展開（Lateral Movement）

侵入後に他システムへ移動して権限拡大を図る行為。単一侵害を全体被害に拡げる主要手口。
