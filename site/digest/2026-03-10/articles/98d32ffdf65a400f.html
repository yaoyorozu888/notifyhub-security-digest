Web Server Exploits and Mimikatz Used in Attacks Targeting Asian Critical Infrastructure

既知Web脆弱性悪用とMimikatzによる内部展開は重大。対象が重要インフラであり運用影響が大きい。情報源はメディアだが一次分析（Unit 42）に基づくため据え置き評価。

概要

アジア地域（南・東南・東アジア）の重要インフラ組織を標的とした、中国系とみられる攻撃キャンペーンが報告された。Palo Alto Networks Unit 42の分析によると、攻撃者はWebサーバの既知脆弱性を悪用して初期侵入を行い、内部展開段階ではMimikatzなどのツールを用いて認証情報を窃取していた。対象には航空・エネルギー・政府・法執行・製薬・通信などが含まれ、長期的な情報収集・持続的アクセス維持を目的とするスパイ活動の様相を呈している。

現場の学び

  • 攻撃は公開Web資産の脆弱性管理の遅れを突いており、パッチ未適用やEoL製品が踏み台となるリスクを再認識すべき。
  • Mimikatz利用は依然として有効であり、LSASSアクセス検知や資格情報保護設定の有無が侵害拡大を左右する。
  • 標的業種の共通点は運用継続性が高く停止許容度が低い点であり、復旧よりも侵入防止・早期検知が重要。

初動・継続対応の示唆

  • 外部公開Webサーバの既知CVE対応状況を棚卸し、特に過去1年以内にRCE報告のあった製品を優先確認。
  • 内部監視では、Mimikatz等によるLSASSプロセスアクセスイベント（例:4624, 4688）を相関分析し、横展開兆候を検知。
  • 長期潜伏型攻撃を想定し、認証情報再発行・特権アカウント監査を定期運用に組み込む。

📌 キーワード解説

Mimikatz

Windowsのメモリから認証情報を抽出するツール。侵入後の権限昇格や横展開に使われる。EDR検知回避手法と併用される点が脅威。

Web server exploit（Webサーバ脆弱性悪用）

公開Webサーバのソフトウェア欠陥を突く攻撃。認証前RCEが多く、初期侵入の主要経路となる。WAFやパッチ管理で対策。

Credential theft（認証情報窃取）

ユーザやサービスの資格情報を奪う行為。フィッシングと異なり、侵入後の内部展開で発生する。

Persistent access（持続的アクセス）

侵入後に長期的な制御を維持する手法。バックドア設置や認証情報保持が典型。短期的なランサム攻撃と対比される。
