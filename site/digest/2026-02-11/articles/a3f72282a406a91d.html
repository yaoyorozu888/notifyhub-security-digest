📌 キーワード解説

SAST (Static Application Security Testing)／静的アプリケーションセキュリティテスト

ソースコードを実行せずに脆弱性を検出する手法。DASTとの違いは実行環境を必要としない点。

DAST (Dynamic Application Security Testing)／動的アプリケーションセキュリティテスト

実行中のアプリケーションを対象に脆弱性を検出する。SASTと対比され、実行時挙動を重視する。

False Positive／誤検知

実際には問題がないのに脆弱性と判定される事象。検知精度の議論でFalse Negative（見逃し）と対比される。

Explainability／説明可能性

AIの判断根拠を人間が理解できる形で提示する性質。ブラックボックス化との対比で信頼性評価に重要。
